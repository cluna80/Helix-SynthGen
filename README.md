## What is HELIX SYNTHGEN?

HELIX SYNTHGEN is a multi-agent autonomous platform that takes a bio-threat report and runs the full countermeasure pipeline — from threat classification to compound design to supply chain procurement — without human intervention until the final deployment decision.

'The AI that designs the antidote before the lab opens.'

In crisis scenarios — military field operations, remote outbreak sites, bioterror events — traditional lab timelines take days. HELIX SYNTHGEN compresses the initial response phase to under 60 minutes computationally.

---

## Agent Architecture

| Agent | Role |
|---|---|
| HELIX-SCOUT | Bio-threat intel. Classifies pathogen, target protein, resistance mutations, urgency tier. |
| HELIX-FORGE | Synthesis agent. Designs 3 lead compounds with binding scores, ADMET profiles, R-group mods. |
| HELIX-CHAIN | Logistics agent. Secures precursor supply chain, sources suppliers, calculates ETA. |
| HELIX-TWIN | Digital twin. Animated canvas — pathogen spread and antidote neutralization in real time. |

Agents chain sequentially. Human only intervenes at the final AUTHORIZE ALLOCATIONS button.

## Run Locally

Prerequisites: Node.js

npm install
npm run dev

Enter your Gemini API key in the UI for live mode. Demo mode requires no key.

---

## Tech Stack

- React + TypeScript + Vite + Tailwind CSS
- Google Gemini 2.0 Flash (REST API)
- HTML5 Canvas 2D — bezier bloodstream paths, particle physics
- Zero backend — runs entirely in the browser
